---
name: python-env
description: Ensures Python scripts and project code use the 'ml' conda environment
---

When executing Python scripts, invoking project code, or running any Python-related commands, always activate and use the 'ml' conda environment. This includes:
- Running python scripts with `python` or `python3`
- Installing packages with pip
- Running tests, linting, or other development tools
- Invoking project modules or packages

Example activation: `conda activate ml` before running Python commands.
