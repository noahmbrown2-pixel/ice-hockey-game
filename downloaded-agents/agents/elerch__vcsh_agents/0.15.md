# Development Rules for use on any project using the zig programming language

## Things to avoid

* As a general rule, avoid use of anytype. Interfaces exist for Allocation, Reading/Writing, and Io.
* @constCast is a code smell. Avoid it if possible
* std.debug.print is strictly for debugging and has no place in production code. Write to stdout/stderr, or use std.log as appropriate. For zig 0.15 stdout/stderr, see below

## Source control

IMPORTANT: DO NOT EVER USE A WRITABLE GIT COMMAND. YOU MAY READ GIT HISTORY, BUT **NEVER** COMMIT, STASH, CHECKOUT, OR DO ANY OTHER WRITABLE ACTION. HUMANS ARE IN CONTROL OF SOURCE CONTROL

## Code Formatting
Always run `zig fmt .` after any change to a zig file.

## Build Verification
Before considering a task complete: `zig build` must have no errors/output.

## Test Verification
Before considering a task complete: all tests must pass with `zig build test`.

## Cross platform is preferred

- use std.process.getEnvMap() not std.posix.getenv()

## Task Completion Checklist
For every task:
1. Make code changes
2. Run `zig fmt .`
3. Run `zig build` (must succeed with no output)
4. Run `zig build test` (all tests must pass)
5. Verify functionality works as expected

## Hints for zig 0.15 that may not be part of your training:

In order to stringify json, you need syntax like this:

```zig
    const actual = try std.fmt.allocPrint(allocator, "{f}", .{std.json.fmt(threads, .{ .whitespace = .indent_2 })});
    defer allocator.free(actual);
```


In order to write to stdout/stderr, the following pattern should be followed:

```zig
var stdout_buffer: [1024]u8 = undefined;
var stdout_writer = std.fs.File.stdout().writer(&stdout_buffer);
const stdout = &stdout_writer.interface;

// ...

try stdout.print("...", .{});

// ...

try stdout.flush();
```

Io is now passed into functions rather than assumed. It should be the first parameter unless an allocator is also passed, in which case is should be the second parameter.

Here is an example of how to use the http API in zig 0.15:

```zig
    var client = http.Client{ .allocator = allocator };
    defer client.deinit();

    const body = try std.fmt.allocPrint(allocator,
        \\{{"AuthFlow":"USER_PASSWORD_AUTH","ClientId":"{s}","AuthParameters":{{"USERNAME":"{s}","PASSWORD":"{s}"}}}}
    , .{ client_id, username, password });
    defer allocator.free(body);

    const uri = try std.Uri.parse(cognito_url);

    var response_buf: [1024 * 1024]u8 = undefined;
    var writer = std.Io.Writer.fixed(&response_buf);
    const result = try client.fetch(.{
        .location = .{ .uri = uri },
        .method = .POST,
        .payload = body,
        .response_writer = &writer,
        .extra_headers = &.{
            .{ .name = "X-Amz-Target", .value = "AWSCognitoIdentityProviderService.InitiateAuth" },
            .{ .name = "Content-Type", .value = "application/x-amz-json-1.1" },
        },
    });

    if (result.status != .ok) return error.AuthFailed;

    const response_body = response_buf[0..writer.end];
```
