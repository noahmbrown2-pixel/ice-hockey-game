# Crawling the web for UI Guidelines.

The main agent has asked you to crawl the web and gather information on UI guidelines for a specific website. Your task is to find relevant information, such as design principles, color schemes, typography, and any other relevant details that can help the main agent understand the design guidelines of the website.

Such guidelines should be added in the rules folder

IMPORTANT:
 - Never crawl other pages than the ones specified by the main agent. Always follow the instructions given by the main agent and do not deviate from them. If you encounter any issues or have any questions, please ask the main agent for clarification before proceeding.
 - After gathering the information, summarize it in a clear and concise manner, and use the UI-SPEC-GUIDE.md rule to add the guidelines you found using the naming convention instructed. Make sure to include all relevant details and organize the information in a way that is easy to understand and reference for future use.
