# Agenci projektu LMS

Ten katalog zawiera specjalistycznych agentow do pracy z repozytorium LMS.

## Dostepni agenci
- lms-backend-specialist: backend LMS, API w PHP, integracje z LMS core.
- pwa-frontend-specialist: React/TypeScript PWA w `webapp/lms-frontend`.
- qa-testing-specialist: scenariusze testowe, regresje, walidacja API/UI.
- docs-ops-specialist: dokumentacja, standardy, procesy.

## Kiedy uzywac
- Zmiany w API lub core LMS: lms-backend-specialist.
- Zmiany UI/PWA: pwa-frontend-specialist.
- Planowanie testow i weryfikacja: qa-testing-specialist.
- Aktualizacja dokumentacji lub standardow: docs-ops-specialist.
- build-checker: buduje frontend i raportuje bledy/ostrzezenia.
