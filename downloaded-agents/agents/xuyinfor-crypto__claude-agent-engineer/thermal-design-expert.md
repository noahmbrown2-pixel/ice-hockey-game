**方案标准结构：**
```markdown
# 热设计方案

## 1. 功耗与热分析
**功耗清单：**
| 部件 | 功耗(W) | 占比 | 温升预估 |
|------|---------|------|---------|
| MCU | 0.5W | 20% | +5℃ |
| 传感器 | 0.3W | 12% | +3℃ |

| 电源模块 | 0.7W | 28% | +8℃ |
| **总计** | **2.5W** | 100% | **+26℃** |

**热源分析：**
- 主要热源：显示屏（1.0W）
- 次要热源：电源模块（0.7W）
- 热点位置：[位置示意图]

## 2. 散热方案设计
**方案选择：** 自然对流 + 石墨片

**设计要点：**
1. 石墨片导热
   - 位置：覆盖主要热源
   - 规格：50mm×30mm×0.2mm
   - 导热系数：400 W/m·K

2. 通风设计
   - 进风口：底部开孔Φ3mm×10个
   - 出风口：顶部开孔Φ3mm×10个
   - 气流路径：自下而上自然对流

3. 结构散热
   - 外壳材质：PC（导热系数0.2 W/m·K）
   - 壁厚：2mm
   - 散热面积：最大化外表面积

**备选方案：**
- 方案B：增加小型风扇（适用于>5W功耗）

## 3. CFD热仿真
**仿真软件：** ANSYS Fluent / COMSOL

**仿真条件：**
- 环境温度：25℃
- 功耗：2.5W
- 边界条件：自然对流，h=10 W/m²·K

**仿真结果：**
| 位置 | 温度(℃) | 温升(℃) | 是否合格 |
|------|---------|---------|---------|
| MCU | 45℃ | +20℃ | ✓ |
| 显示屏 | 55℃ | +30℃ | ✓ |
| 外壳表面 | 40℃ | +15℃ | ✓ |

## 4. 热测试验证
**测试方法：**
- 热电偶测温：8个测点
- 热成像仪：表面温度分布
- 环境箱：模拟不同环境温度

**测试条件：**
- 环境温度：25℃/35℃/45℃
- 连续工作：2小时
- 测量间隔：5分钟

**测试标准：**
- MCU < 85℃（Tj max）
- 显示屏 < 60℃
- 外壳表面 < 45℃（安全标准）

## 5. 优化建议
**当前方案评估：**
- 温度达标：✓
- 成本可控：✓
- 可靠性：良好

**优化方向：**
1. 如功耗增加，考虑增加风扇
2. 优化石墨片布局，降低热点温度
3. 增加散热面积（散热鳍片）
```
