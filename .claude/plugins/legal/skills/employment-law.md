## Employment Law Framework

### Key Employment Laws (US)

| Law | Coverage | Key Requirements |
|-----|----------|------------------|
| **Title VII** | 15+ employees | No discrimination (race, religion, sex, national origin, color) |
| **ADA** | 15+ employees | Disability accommodations |
| **ADEA** | 20+ employees | Age discrimination (40+) |
| **FMLA** | 50+ employees | 12 weeks unpaid leave |
| **FLSA** | Most employers | Minimum wage, overtime, child labor |
| **OSHA** | Most employers | Workplace safety |
| **NLRA** | Most private | Union rights |

### Termination Considerations

#### Before Termination
- [ ] Review personnel file
- [ ] Document performance issues
- [ ] Check protected class status
- [ ] Review any complaints filed
- [ ] Confirm at-will status
- [ ] Check for retaliation risk
- [ ] Review contractual obligations
- [ ] Consider timing implications

#### Termination Types
| Type | Requirements | Considerations |
|------|--------------|----------------|
| At-will | None (generally) | Can be challenged |
| For cause | Documentation | Define "cause" clearly |
| Layoff/RIF | Consistency | WARN Act (100+ employees) |
| Resignation | Accept in writing | Confirm voluntary |

### Discrimination & Harassment

#### Protected Classes (Federal)
- Race
- Color
- Religion
- Sex (including pregnancy, gender identity)
- National origin
- Age (40+)
- Disability
- Genetic information

#### Investigation Framework
```markdown
## Investigation Steps

1. **Receive Complaint**
   - Document immediately
   - Acknowledge receipt
   - No retaliation warning

2. **Preserve Evidence**
   - Litigation hold if needed
   - Secure documents
   - Preserve electronic records

3. **Investigate**
   - Interview complainant
   - Interview accused
   - Interview witnesses
   - Review documents

4. **Analyze**
   - Assess credibility
   - Apply preponderance standard
   - Document findings

5. **Conclude**
   - Make determination
   - Decide corrective action
   - Communicate appropriately

6. **Follow Up**
   - Monitor for retaliation
   - Document resolution
```

### Contractor vs Employee

| Factor | Employee | Contractor |
|--------|----------|------------|
| Control over work | Employer directs | Self-directed |
| Tools/equipment | Employer provides | Contractor provides |
| Financial risk | None | Bears risk |
| Permanence | Ongoing | Project-based |
| Benefits | Receives | None |
| Taxes | Withheld | 1099 |

**Misclassification Risks**:
- Back taxes and penalties
- Benefits liability
- Workers' comp claims
- Unemployment claims
- Wage and hour violations
