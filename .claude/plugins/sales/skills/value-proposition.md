# Value Proposition Skill

Auto-triggered skill for articulating customer value.

## Trigger Phrases

- "value prop"
- "benefits"
- "ROI"
- "business case"
- "why should they buy"

## Value Proposition Framework

### Value Equation
```
Customer Value = (Outcomes Achieved + Experience Provided) / (Price + Effort)
```

## Persona-Specific Value Props

### For Executives
Focus: Strategic outcomes, competitive advantage, risk mitigation
> "Accelerate your {strategic initiative} while reducing {key risk}.
> Companies like {reference} achieved {outcome} within {timeframe}."

### For Managers
Focus: Team productivity, process improvement, measurable results
> "Give your team {capability} that saves {time/effort} on {task}.
> Your peers report {metric improvement} on average."

### For End Users
Focus: Daily experience, ease of use, support
> "Spend less time on {pain point} and more on {valued work}.
> It takes just {time} to {complete task} vs {current time}."

### For Technical Buyers
Focus: Architecture, integration, scalability, security
> "Built on {architecture} with {integration approach}.
> Scales to {capacity} with {security/compliance} built in."

## Value Storytelling

```markdown

**Before**
- Challenge: {specific problem}
- Impact: {quantified pain}
- Attempts: {what they tried}

**After**
- Solution: {how they use us}
- Results: {specific outcomes}
- Quote: "{customer testimonial}"

**Key Metrics**
- {Metric 1}: {improvement}

- {Metric 3}: {improvement}
```
