## Core Formulas

### AIDA (Awareness → Interest → Desire → Action)

```
ATTENTION: Hook that stops the scroll
"Stop losing customers to slow load times"

INTEREST: Engage with relevant benefits
"Our customers see 3x faster page loads and 40% higher conversion"

DESIRE: Build wanting with proof
"Join 10,000+ businesses who've transformed their user experience"

ACTION: Clear CTA
"Start your free trial today"
```

### PAS (Problem → Agitate → Solution)

```
PROBLEM: Identify the pain
"Tired of spending hours on manual data entry?"

AGITATE: Twist the knife
"Every minute you waste on repetitive tasks costs you money,
frustrates your team, and lets competitors pull ahead."

SOLUTION: Present the answer
"Automate your workflows in minutes with [Product]"
```

### AICPBSAWN (Long-form formula)

```
Attention → Interest → Credibility → Prove → Benefits →
Scarcity → Action → Warn → Now
```

### BAB (Before → After → Bridge)

```
BEFORE: Current painful state
"You're drowning in spreadsheets, missing deadlines, and working
late every night."

AFTER: Dream state achieved
"Imagine finishing work at 5pm, knowing everything is tracked and
nothing will slip through the cracks."

BRIDGE: Your solution connects them
"[Product] is the project management tool that makes this reality."
```

### 4 Ps (Picture → Promise → Prove → Push)

```
PICTURE: Paint the scenario
PROMISE: Make the commitment
PROVE: Back it up
PUSH: Call to action
```

## Headline Formulas

### Question Headlines
- "Are you making these {X} mistakes in {topic}?"
- "What if you could {desirable outcome}?"
- "Do you know the secret to {result}?"

### Number Headlines
- "{X} ways to {achieve result}"
- "The {X} biggest mistakes in {topic}"
- "{X}% of {group} don't know this about {topic}"

### How-To Headlines
- "How to {achieve result} in {timeframe}"
- "How to {achieve result} without {common pain}"
- "How {authority figure} achieves {result}"

### Curiosity Headlines
- "The surprising reason {unexpected outcome}"
- "What {successful people} know about {topic} that you don't"
- "The {adjective} truth about {topic}"

### Benefit Headlines
- "Get {result} in {timeframe}"
- "Finally, {solution to common problem}"
- "The fastest way to {desirable outcome}"

## Power Words

### Urgency
Now, Today, Hurry, Limited, Last chance, Don't miss

### Value
Free, Bonus, Exclusive, Premium, Best-selling

### Emotion
Discover, Imagine, Transform, Revolutionary, Breakthrough

### Trust
Proven, Guaranteed, Certified, Research-backed, Trusted

### Ease
Simple, Easy, Quick, Effortless, Instant

## Sentence Structures

### Open Loops
Start with incomplete thought that demands resolution

### Bucket Brigades
"But that's not all..."
"Here's the thing..."
"Now, here's where it gets interesting..."

### Pattern Interrupts
Short. Sentences. For. Impact.

(And parenthetical asides for intimacy)
