# Content Calendar Skill

Auto-triggered skill for planning and scheduling content.

## Trigger Phrases

- "content plan"
- "calendar"
- "schedule posts"
- "editorial"
- "content schedule"

## Content Pillars

### Pillar Strategy
```
Content Pillars
├── Pillar 1: {Topic Area}
│   ├── Sub-topic A
│   ├── Sub-topic B
│   └── Sub-topic C
│
├── Pillar 2: {Topic Area}
│   ├── Sub-topic A
│   ├── Sub-topic B
│   └── Sub-topic C
│
└── Pillar 3: {Topic Area}
    ├── Sub-topic A
    ├── Sub-topic B
    └── Sub-topic C
```

### Content Ratio (80/20 Rule)
- 80% Value content (educate, entertain, inspire)
- 20% Promotional content (sell, convert)

## Planning Process

### Quarterly Planning
1. Review previous quarter performance
2. Align with business objectives
3. Identify key themes and campaigns
4. Set content targets
5. Assign owners and deadlines

### Weekly Planning
1. Review upcoming week's calendar
2. Confirm content is ready
3. Schedule posts
4. Prepare engagement plan
5. Note any adjustments needed

## Status Indicators

```
⚪ Not Started
🟡 In Progress
🟢 Ready/Published
🔴 Blocked/Delayed
```
