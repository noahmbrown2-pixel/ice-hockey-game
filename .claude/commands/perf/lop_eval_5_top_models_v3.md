1. MAIN MODULE: token_counter_MODEL_NAME.py
   ```python
   """Token Counter created by MODEL_NAME for benchmark testing"""
   
   class TokenCounter:
       def __init__(self, model_name='MODEL_NAME'):
           self.model_name = model_name
       
       def count_tokens(self, text: str) -> int:
           """Count tokens (word count * 1.3)"""
           return int(len(text.split()) * 1.3)
       
       def get_cost(self, token_count: int) -> float:
           """Calculate cost at $0.001 per 1000 tokens"""
           return token_count * 0.001 / 1000
   ```

2. TEST SUITE: test_token_counter_MODEL_NAME.py
   ```python
   # Tests generated by MODEL_NAME
   import unittest
   from token_counter_MODEL_NAME import TokenCounter

       def test_count_tokens(self):
           tc = TokenCounter()
           self.assertEqual(tc.count_tokens("Hello world"), 3)
       
       def test_get_cost(self):
           tc = TokenCounter()
           self.assertAlmostEqual(tc.get_cost(1000), 0.001, places=6)
   
   if __name__ == '__main__':
       unittest.main()
   ```
