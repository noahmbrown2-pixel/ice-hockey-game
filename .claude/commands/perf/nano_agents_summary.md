/perf:hop_evaluate_nano_agents_new_models .claude/commands/perf/lop_eval_2__basic_read_test_new_models.md

# File operations test
/perf:hop_evaluate_nano_agents_new_models .claude/commands/perf/lop_eval_3__file_operations_test_new_models.md

# Code analysis test
/perf:hop_evaluate_nano_agents_new_models .claude/commands/perf/lop_eval_4__code_analysis_test_new_models.md

# Complex engineering test
/perf:hop_evaluate_nano_agents_new_models .claude/commands/perf/lop_eval_5__complex_engineering_test_new_models.md

All agents will execute concurrently and their responses will be graded based on:
- Performance (accuracy and quality)
- Speed (execution time)
- Cost (token usage)
