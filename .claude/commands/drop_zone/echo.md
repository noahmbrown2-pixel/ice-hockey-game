# Echo Command

## Purpose
Read and display the contents of the dropped file.

## Variables
- `[[FILE_PATH]]` - The absolute path to the file that was dropped

## Task
Please read the file at `[[FILE_PATH]]` and display its contents.

After reading the file, provide a brief summary of:
1. File type and format
2. Number of lines (if text-based)
3. Key content or structure observed
4. Any notable patterns or data points

Then echo the full contents in a formatted code block appropriate for the file type.

## Output Format
Present the results in a clean, organized manner with:
- A header showing the file name
- Summary statistics
- The complete file contents in a code block
