## Exception Handling

<!-- @REQ-WKFL-010: Comprehensive error recovery strategies | BLP: [Durability: Self-Healing, Alignment: Reliable] -->

### Lifelog API Failure
- **Detection:** HTTP 5xx, timeout
- **Recovery:** Retry 3x with exponential backoff, skip cycle if persists
- **Notification:** Log only (no alert)

### TB Parse Error
- **Detection:** LLM timeout or invalid JSON response
- **Recovery:** Save raw text, mark for manual review
- **Notification:** WhatsApp notification with raw command

### Notion API Failure
- **Detection:** 429 rate limit, 5xx errors
- **Recovery:** Queue request, retry after delay
- **Notification:** Email if queue exceeds 10 items

### Notification Delivery Failure
- **Detection:** Both Nostr and WhatsApp fail
- **Recovery:** Store in database for retry, proceed to approval wait
- **Notification:** Log warning, retry hourly

### Approval Timeout
- **Detection:** 24 hours elapsed
- **Recovery:** Auto-expire, update Notion, notify user
- **Notification:** WhatsApp + Email with command summary

### ZTE Execution Failure
- **Detection:** GitHub issue creation fails or DITD phase errors
- **Recovery:** Retry 3x, fallback to direct agent execution
- **Notification:** WhatsApp URGENT alert

### Result Delivery Failure
- **Detection:** All delivery channels fail
- **Recovery:** Store in filesystem, retry hourly
- **Notification:** Email alert to sysadmin
