SECTOR

INFINITE ESCAPE PROTOCOL · 3D

You wake in a pitch-black sector cell with only a flashlight. The exit door is boarded shut with planks, and a heavy metal vault sits in the dead centre — it will only show the full escape code once you've collected all four code numbers. There is no code readout on screen: the vault is the only place to see it.

It's a two-storey home split into bedrooms, living rooms and kitchens. Hidden in the furniture are 4 code numbers — 2 on the ground floor and 2 upstairs — plus a 🔑 KEY and a 🔨 HAMMER. The only way upstairs is the ladder at the stairwell (stand on it and hold SPACE / CLIMB, then step off onto the upper floor). Drawers slide open as you look at them; nothing is grabbed automatically — aim at an item and press E (or tap PICK UP). Use the key to open the vault and read the assembled code, smash the door planks with the hammer, then press E at the door and type the code to escape. You can't squeeze under the furniture — go around. Some sectors swap the code for a sliding 4×4 grid puzzle at the door — just find the hammer, smash the planks, and solve the grid to escape. The only way up is a tight shaft at the ladder.
